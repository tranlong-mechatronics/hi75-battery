# hi75-battery

A lightweight, dedicated battery monitor for the **Leobog Hi75C Pro** mechanical keyboard on Windows.

## Device Identification
- **Wired:** `VID_258A & PID_010C` (SinoWealth / BY Tech)
- **2.4 GHz Dongle:** `VID_3554 & PID_FA09`
- **Telemetry Interface:** Usage Page `0xFF02`, Usage `0x0002`
- **Protocol:** 20-byte Feature Report starting with `0x13, 0xCA`
